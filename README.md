# gestor_biblioteca
## Descripción

`gestor_biblioteca` es una aplicación diseñada para gestionar bibliotecas de manera eficiente. Permite a los usuarios realizar un seguimiento de libros, autores, préstamos y devoluciones.

## Características

- Gestión de libros: agregar, editar y eliminar libros.
- Gestión de autores: asociar libros con sus respectivos autores.
- Registro de préstamos y devoluciones.
- Búsqueda y filtrado de libros por título, autor o categoría.

## Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/pablousky4/gestor_biblioteca.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd gestor_biblioteca
    ```
3. Instala las dependencias necesarias:
    ```bash
    pip install -r requirements.txt
    ```

## Uso

1. Ejecuta la aplicación:
    ```bash
    python main.py
    ```
2. Sigue las instrucciones en pantalla para interactuar con el gestor de biblioteca.
